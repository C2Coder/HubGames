# SPŠ Trutnov logo

Original SVG downloaded from the school's website:
https://www.spstrutnov.cz/images/logo-spstrutnov-4.svg

Author: Luděk Dušek. The same school artwork is published as CC BY-SA 4.0:
https://commons.wikimedia.org/wiki/File:Logo_SP%C5%A0_Trutnov.svg
https://creativecommons.org/licenses/by-sa/4.0/

`sps-trutnov.svg` preserves the downloaded source. `school_logo.h` is a cropped,
48×48, one-bit adaptation of its emblem, with the blues unified to the school
blue #008ACC. The adapted artwork is also CC BY-SA 4.0. It uses only that blue
and white on the LED panels. Generate it with `tools/prepare_school_logo.py`
(Pillow + CairoSVG on the development machine; no runtime dependency).
